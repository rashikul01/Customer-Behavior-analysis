# Customer Behavior analysis
Data analytics project showcasing customer behavior analysis using python, sql, powerbi


Project Overview

This project demonstrates an end-to-end Data Analytics workfloww, from raw dataset processing to interactive dashboard creation.

The project covers:

* Data loading and exploration using Python
* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Data analysis using PostgreSQl
* SQL queries to extract business insights
* Interactive dashboard development using Power BI

---

 Tools & Technologies

* Python – Pandas, NumPy, Matplotlib
* SQL – PostgreSQL
* Power BI– Data visualization and dashboard development
* Jupyter Notebook – Data analysis and EDA

---

 Project Workflow

1. Data Loading

Loaded the raw dataset into Python using Pandas and examined its structure, columns, data types, and basic statistics.

 2. Data Cleaning

Performed data preprocessing to improve data quality, including:

* Handling missing values
* Removing duplicate records
* Correcting data types
* Checking inconsistent or invalid values
* Preparing data for analysis

3. Exploratory Data Analysis

Performed EDA using Python to identify patterns, trends, and relationships within the dataset.

Key activities included:

* Descriptive statistics
* Distribution analysis
* Category-wise analysis
* Correlation analysis
* Data visualization

  
4. PostgreSQL & SQL Analysis

Loaded the cleaned dataset into PostgreSQL and used SQL queries to answer business-related questions.

SQL concepts used include:

* `SELECT`
* `WHERE`
* `GROUP BY`
* `ORDER BY`
* Aggregate functions
* `CASE WHEN`
* Subqueries
* CTEs
* Window functions
* Joins

 5. Power BI Dashboard

Created an interactive Power BI dashboard to present the key findings in an easy-to-understand format.

The dashboard includes:

* KPI cards
* Charts and graphs
* Category-wise analysis
* Trend analysis
* Interactive filters/slicers
* Business insights



Key Outcomes

The project helped transform raw data into meaningful insights through a complete analytics workflow.
